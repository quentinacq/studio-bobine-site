─────────────────────────────────────────────
2. POUR VOIR LE SITE SUR VOTRE ORDINATEUR
─────────────────────────────────────────────

  Double-cliquez sur "index.html".
  Il s'ouvre dans votre navigateur. Tous les menus,
  les articles et la page Événements fonctionnent
  tant que les fichiers restent dans ce dossier.

  NOTE : les liens du menu comme "Devis", "Réalisations"
  ou "Conseils" ne sont pas des pages séparées — ce sont
  des sections de la page d'accueil. Cliquer dessus fait
  DÉFILER la page jusqu'à la bonne section. C'est normal.


─────────────────────────────────────────────
3. POUR METTRE LE SITE EN LIGNE (gratuit)
─────────────────────────────────────────────

  Option simple, sans compétence technique :

  1. Allez sur https://app.netlify.com/drop
     (ou Cloudflare Pages, ou GitHub Pages)
  2. Glissez-déposez CE DOSSIER ENTIER sur la page.
  3. Le site est en ligne en quelques secondes, avec
     une adresse temporaire.
  4. Reliez ensuite votre nom de domaine (ex.
     studiobobine.fr) dans les réglages.

  Comme la page d'accueil s'appelle "index.html",
  elle s'affichera automatiquement à l'ouverture du site.

─────────────────────────────────────────────
5. REMPLACER LES IMAGES PAR DE VRAIES PHOTOS
─────────────────────────────────────────────

  Chaque image du site porte un attribut "data-local"
  qui indique le nom de fichier prévu (ex.
  data-local="hero/couple-lac.jpg").

  Pour mettre vos propres photos : créez un dossier
  "images/" dans ce dossier, déposez-y vos photos avec
  ces noms, puis remplacez dans le code le "src" en
  base64 par le chemin, ex : src="images/hero/couple-lac.jpg".

  (Un guide dédié vous a été fourni : "GUIDE-images.md".)
