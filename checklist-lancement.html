Bloquant — le site ne peut pas partir sans ça

Acheter un nom de domaine

Bloquant

Réservez votre adresse (ex. studiobobine.fr) chez un registraire comme OVH, Gandi ou Namecheap. C'est l'adresse que taperont vos clients. Comptez ~10-15 €/an.

→ Vous (5 min)
✓

Choisir un hébergement et mettre le site en ligne

Bloquant

Le site est un ensemble de fichiers HTML : un hébergement statique gratuit suffit (Netlify, Cloudflare Pages, GitHub Pages). Vous y déposez tous les fichiers .html, le sitemap et le robots.txt, puis reliez votre domaine.

→ Vous / un proche techos (30 min)
✓

Brancher les formulaires (Formspree)

Bloquant

Sans ça, aucune demande ne vous parvient. Créez un compte Formspree gratuit, créez deux formulaires, et remplacez VOTRE_ID_CONTACT et VOTRE_ID_LEADMAGNET dans le code. Testez ensuite un envoi réel.

→ Vous (15 min)
✓

Remplacer les coordonnées par les vraies

Bloquant

Numéro WhatsApp (le 33600000000 est fictif), liens réseaux sociaux, et le domaine studiobobine.fr partout dans le code (balises SEO, sitemap, canonical). L'adresse email est déjà en place : hello.studiobobine@gmail.com.

→ Vous / moi si vous me les donnez

Bloquant

Bloquant

L'ordre que je recommande pour lancer vite

  1. Nom + domaine + tarifs — les décisions à figer d'abord.
  2. Coordonnées réelles + Formspree — pour que le site fonctionne vraiment.
  3. Mentions légales + confidentialité — l'obligation à ne pas oublier.
  4. Mise en ligne (hébergement + domaine) — le site devient public.
  5. Google Business + Search Console — pour exister sur Google dès J1.
  6. Test mobile complet — le dernier contrôle avant d'annoncer.

En résumé : le site est techniquement prêt et complet. Ce qui manque n'est pas du développement, mais vos décisions et vos contenus réels (nom, tarifs, coordonnées, mentions légales, vraies images) plus la mise en ligne. Le vrai minimum bloquant tient en 7 points — le reste peut suivre une fois ouvert.
